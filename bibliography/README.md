# Bibliography
This directory contains the bibliographic references supporting my doctoral research on AI-based modelling and decision support for CSP-driven MED-TVC desalination systems.
The references are managed using Zotero and exported in BibTeX format.

Main research areas:
- CSP and renewable-energy-driven desalination
- MED-TVC modelling and performance analysis
- Machine learning and surrogate modelling
- Multi-objective optimization and decision support
- Nanofiltration pretreatment

The bibliography contains metadata for scientific publications and does not include confidential research datasets.
