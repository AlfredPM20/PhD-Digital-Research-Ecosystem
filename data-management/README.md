# Data Management Plan
This directory contains the Data Management Plan (DMP) developed for my doctoral research on AI-based modelling and multi-criteria decision support for CSP-driven MED-TVC desalination.
The DMP describes the management of numerical simulation datasets, documentation, storage, backups, reproducibility, data protection, and long-term preservation.

## Data Storage and Access
Research data are stored on Google Drive and backed up on a USB flash drive.
The underlying research datasets and restricted project code are not publicly shared, following supervisory guidance and applicable research collaboration agreements.

## FAIR Principles
The research follows FAIR data management principles through metadata documentation, consistent file formats, clear data provenance, and controlled access where appropriate.
